**目的**：建立 CSS 变量 token 体系 + 主题切换机制 + Naive UI 主题覆盖，
为后续所有页面的视觉优化提供统一地基。

**⚠️ 关键**：本阶段未完成不得开始任何页面美化任务。

- [x] T001 创建 `webui/src/styles/tokens.css`：按 plan.md §1.1 的**双配色体系** token 定义，

  以及阅读器专属 token（墨林墨绿配色，仅阅读器内部使用）的三套主题（light / eye-care / dark）；

## Phase 2：阅读器体验打磨（核心价值页，P1）

**目标**：按 plan.md §2 的设计，把阅读器从功能框架升级为精致阅读体验。

- [x] T006 [P] 阅读页顶部工具栏重设计：ReaderView.vue 的顶部栏从朴素返回 + 标题 + 下载
  改为精致工具栏——左侧返回链接（返回 + 标题 + fake_mode 徽章），
  右侧控制区：A- / A+ 字号按钮、三主题切换（浅色/护眼/暗色图标按钮组）、下载按钮；

  整体风格简约精致，黑白灰为主，无渐变。

- [x] T007 [P] 阅读器主题系统：在 tokens.css 中（或单独 reader.css）定义阅读器三套主题的 CSS 变量：

- [x] T008 [P] 字号与行高调节：在阅读器内容区通过 CSS 变量

- [x] T009 [P] 章节导航精致化：左侧导航栏从朴素列表改为精致导航——

  active 项文字加粗 + 浅灰背景；
  滚动使用 IntersectionObserver 同步高亮当前章节；
  点击导航项 smooth scroll 到对应章节；
  导航栏上方加「目录」小字标签（全大写/浅色）。

- [x] T010 [P] 正文排版优化：阅读器正文区最大宽度 720px + 居中，
  两侧留白；正文字号/行高消费 reader token；段落间距调整为更舒适的阅读节奏；
  章节标题（h2）左侧加 3px 墨绿竖线装饰 + 左内边距；
