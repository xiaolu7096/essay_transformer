## 0. 总览

本特性是**纯前端 UI 优化**，不改动任何后端代码、不改动 core/、不引入新的运行时重依赖。
目标是把 003 交付的「功能框架」打磨成「有设计感的产品」。

整体设计方向：**双配色体系**——
- **阅读页**：墨林墨绿（米灰底 `#faf8f3` + 暖灰字 `#3d3a33` + 墨绿 `#3d7a52` 点缀），护眼舒适，学术感

## 1. 设计系统（Design Tokens）

### 1.1 方案：CSS 变量 + data-theme 属性（双配色体系）

**核心设计：两套 token 体系**
- 全局 token（`--bg-*`、`--text-*` 等）：用于非阅读页面，走「柔墨」灰调
- 阅读器 token（`--reader-*` 或 `data-reader-theme`）：用于阅读页内部，走「墨林墨绿」暖调
- 两套 token 通过命名空间或属性选择器隔离，互不干扰

### 1.2 主题切换机制

```text
初始化：
  localStorage.getItem('app-theme')
    ├─ 有值 → 直接用（light/dark）
    └─ 无值 → matchMedia('(prefers-color-scheme: dark)').matches
              ├─ true  → dark
              └─ false → light
  然后 document.documentElement.setAttribute('data-theme', theme)

切换：
  点击按钮 → toggle(light/dark)
  → setAttribute
  → localStorage.setItem('app-theme', theme)
```

**防 FOUC（无样式内容闪烁）**：在 `<head>` 最顶部的内联 `<script>` 中同步读取 localStorage 并设置
`data-theme`，确保 CSS 加载时就有正确的主题属性，不会出现白屏闪烁。

### 1.3 Naive UI 主题覆盖策略

Naive UI 的默认样式需要和设计系统对齐。方案：

1. 使用 Naive UI 的 `n-config-provider` 设置 `theme-overrides` 覆盖主要 token（颜色、圆角等）
2. 组件级样式通过 CSS 变量覆盖（Naive UI 大量使用 CSS 变量，可以通过 `:root` 覆盖）
3. 实在无法通过变量覆盖的，用深度选择器（`:deep()`）局部覆盖，不使用 `!important`

### 2.2 阅读主题（3 套）

阅读器主题独立于全局主题，各自记忆。但默认跟随全局：
- 全局 light → 阅读器默认 light
- 全局 dark → 阅读器默认 dark
- 用户在阅读器内手动切换后，以阅读器本地记忆为准

| 主题 | 背景色 | 文字色 | 适用场景 |
|------|--------|--------|----------|
| **浅色** | `#faf8f3`（米灰） | `#3d3a33`（暖深灰） | 默认，明亮环境，墨林墨绿主调 |
| **护眼** | `#faf6ee`（羊皮纸米黄） | `#5c4a3a`（深棕） | 长时间阅读、夜间柔和光 |
| **暗色** | `#1a1f1b`（深绿灰） | `#d0d4cc`（浅绿灰） | 夜间环境、OLED 屏省电 |

实现方式：给阅读器容器加 `data-reader-theme` 属性，CSS 内按属性选择器覆盖。
阅读器配色与全局配色（柔墨）独立，保证阅读页的暖调护眼质感。

### 2.3 字号与行高

- **字号**：5 档—— `12 / 14 / 16 / 18 / 20` px，默认 14/16px（正文/标题），A- / A+ 步进 2px
- **行高**：3 档—— `1.6 / 1.8 / 2.0`，默认 1.85
- 实现：给阅读器内容区加 `style` 或 CSS 变量，正文字号 = `--reader-font-size`，行高 = `--reader-line-height`
- 公式大小：KaTeX 字号随正文字号按比例调整（用 `--katex-font-size` 覆盖）

### 2.4 阅读进度条

- 位置：顶部工具栏下方，2px 高
- 计算：`scrollTop / (scrollHeight - clientHeight) * 100%`
- 监听 scroll 事件（可加 `requestAnimationFrame` 节流）

### 2.5 章节导航高亮同步

- 使用 `IntersectionObserver` 监听每个章节标题元素的可见性
- 当前可见性最高的章节 → 导航栏对应项高亮
- 点击导航 → `scrollTo({ behavior: 'smooth' })` 到对应章节

### 2.6 图片灯箱

```text
点击图片 → 创建遮罩层（fixed, fullscreen, bg=rgba(0,0,0,0.85)）
  └─ 居中显示大图（max-width: 90vw, max-height: 90vh）
  └─ 右上角关闭按钮
  └─ 点击遮罩 / ESC 键 / 关闭按钮 → 销毁遮罩层
```

实现：一个全局的 ImageLightbox 组件，或阅读器内局部实现（本阶段先做阅读器内局部即可）。

### 2.7 折叠区动画

原生 `<details>` 不支持高度动画。方案：

- 用自定义组件替换原生 details（或包裹一层）
- 展开时：测量内容 scrollHeight → 设置 height → 过渡到 scrollHeight → 过渡完成后设 height: auto
- 收起时：设置 height 为当前像素值 → 下一帧过渡到 0
- 保持 `<details>` 的语义和无障碍（使用 `aria-expanded`）

或者更简单：使用 CSS `grid` trick——
```css
details[open] .content { grid-template-rows: 1fr; }
details .content { display: grid; grid-template-rows: 0fr; transition: grid-template-rows 0.3s ease; }
details .content > div { overflow: hidden; }
```
纯 CSS 实现，不需要 JS 测量高度。

### 2.8 正文最大宽度

阅读器正文容器 `max-width: 720px`，`margin: 0 auto`，两侧留白。
保证长文阅读时每行约 60–75 字的最佳阅读宽度。

## 5. 响应式与微交互

### 5.1 断点

| 断点 | 宽度 | 布局变化 | 优先级 |
|------|------|----------|--------|
| 桌面 | ≥1024px | 完整布局，侧边导航展开 | P0 |
| 平板 | 768–1023px | 内容区缩放，导航可能变窄或收起 | P2 |
| 手机 | <768px | 单列布局，汉堡菜单，导航抽屉 | P2（能用就行） |

手机端目标：**能用就行**——核心功能可达，无横向滚动条，不追求像素级精致。

### 5.2 移动端导航抽屉（左侧滑出）

- 顶部导航栏左侧汉堡按钮（☰）
- 点击后从**左侧**滑出抽屉 + 半透明遮罩
- 抽屉内：Logo + 导航项列表 + 用户信息 + 主题切换 + 退出登录
- 点击遮罩或返回键关闭
- 抽屉有过渡动画（translateX + 透明度）

### 5.3 三态视觉规范（加载/空态/错误态统一）

三种状态统一设计语言，全站一致：

| 状态 | 图标风格 | 主文字 | 副文字 | 操作按钮 |
|------|---------|--------|--------|---------|
| **加载中** | shimmer 骨架屏 | — | — | — |
| **空态** | 简约几何 SVG | 标题级文字 | 说明文字 + 引导 | 主按钮 |
| **错误态** | 简约几何 SVG（带语义色） | 错误标题 | 错误说明 | 重试按钮 |

统一规范：
- 居中布局，上下留白充足
- 图标尺寸：64-80px
- 标题字号：18-20px，600 字重
- 描述字号：14px，三级文字色
- 按钮：主按钮 + 次按钮（或仅有一个主按钮）
- 配色：与柔墨色系统一

**骨架屏适用页面**：
- 任务列表页 ✓
- 任务详情页 ✓
- 阅读器 ✗（不需要）
- 设置页 ✗（不需要）

### 5.4 微交互

- **路由切换**：淡入淡出过渡，200ms，`opacity` 从 0 → 1
- **按钮 hover**：`transform: translateY(-1px)` + 阴影加深，150ms
- **按钮 active**：`transform: translateY(0)` + 颜色加深
- **卡片 hover**：`transform: translateY(-2px)` + `shadow-lg`，200ms
- **元素渐入**：列表/卡片进入视口时 stagger 渐入（延迟 50ms 每项）
- **所有过渡**：统一使用 token 中的 `--transition-*` 变量

### 5.5 减少动效

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

全站生效，包含 Landing 页的 blob 漂浮、按钮扫光等装饰性动画。

## 8. 验收方式

- **功能回归**：003 的所有功能（提交、实时进度、阅读、下载、密钥、登录注册）在新 UI 下零回归
- **视觉走查**：每个页面在浅色/暗色主题下逐一检查，无硬编码颜色、无错位、无不可读文字
- **响应式走查**：桌面/平板/手机三断点下各页面无横向滚动条、核心功能可达
- **性能检查**：`npm run build` 后 dist 产物 gzipped 体积增幅 ≤15%
- **无障碍**：正文对比度 WCAG AA 达标，键盘 Tab 导航可达所有主要操作
- **假模式验证**：假模式下所有 UI 元素正确显示（演示徽章、假数据等）
