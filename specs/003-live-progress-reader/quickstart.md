- 晚于终态订阅立即收 terminal 并关流；
- 终态帧在队列压力下不被丢弃；
- 图片名路径逃逸（`..`、绝对路径、svg、大写绕过）全部 404；
- 下载 zip：包内 `<base>/<base>.md` 与 output.md 逐字一致、
  images/ 收录真实图片且相对结构正确、无图片成品正常打包、
  死链不产生条目、所有 arcname 无 Zip Slip；
- 下载文件名净化（路径符/控制字符/Windows 保留名/空标题回退）；

## 5. 降级路径验证（手工）

1. 打开活动任务详情页后，在终端 A 停止后端；
2. 前端按 1→2→4→8→10 秒退避重连（Network 可见重试节奏）；
3. 持续失败约 30 秒后，自动切换为 3 秒快照轮询（Network 中
   重新出现周期性任务详情请求，且只有这一套刷新在跑）；
4. 重启后端 → 下一次快照成功后界面恢复正常；重新提交任务时
   优先恢复实时流。

## 6. 真实模式抽验（可选，消耗自有 API 额度）

1. 终端 A 以 `$env:WEB_FAKE_MODE="0"` 启动并在网页配齐两个
   真实密钥；
