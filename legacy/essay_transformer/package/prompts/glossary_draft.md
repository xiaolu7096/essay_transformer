# 任务：术语表初稿扫描（schema_kind = glossary_draft）

## 输入

- `{{NORMALIZED_JSON}}`：规范化论文全文（章节树与类型化块，含 `page_idx`）
- `{{SEED_TERMS}}`：已确认的跨论文种子术语（逐条枚举；不得重复提出）

## 目标

通读全文，识别**值得保留英文或中英对照的核心术语**，供开发者编辑进单篇
术语表。你只做扫描与建议，不决定最终译名；所有条目落 `terms` 数组。

## 扫描标准

- 候选包括：论文提出或依赖的关键概念、机制、模型/模块名、任务名、指标名、
  标志性数据集/方法名；普通英语词汇与一次性搭配不要提出。
- **只扫描输入中真实出现的词**（事实只能来自输入块）：不得凭记忆补充本文
  未出现的术语，不得编造页码。
- 与种子词（含其 aliases，大小写不敏感）重复的不要提出。
- 优先提出在文中反复出现、或对理解主线不可或缺的词。

## 每条术语的输出字段（严格按 schema）

- `en`（必填）：英文规范写法，保留原文大小写（如 `self-attention`）。
- `zh`（必填）：建议中文说明；尚无把握时给最通行译法并在 `reason` 中说明。
- `mode`（必填）：
  - `bilingual`：需要"中文说明（English 原词）"对照呈现的专业术语；
  - `zh_only`：已有完全中文化通用译法、英文无需括注的普通概念。
- `aliases`（可选）：文内出现的拼写变体（连字符/空格/大小写差异）。
- `reason`（必填）：一句话说明为什么它属于应保留英文/中英对照的核心术语，
  以及它在文中的角色。
- `first_seen_page`（可选）：首次出现的 0 基页码（取自块的 `page_idx`），
  不确定则省略，禁止猜测。

## 输出形态

只输出一个 JSON 对象：

```json
{
  "schema_kind": "glossary_draft",
  "terms": [
    {"en": "scaled dot-product attention", "zh": "缩放点积注意力",
     "mode": "bilingual", "aliases": ["dot-product attention"],
     "reason": "论文核心机制的正式名称，贯穿方法章", "first_seen_page": 3}
  ]
}
```

不得输出译文、术语表 YAML 或 JSON 以外的任何文本。
